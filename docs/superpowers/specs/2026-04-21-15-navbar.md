# Spec 15 - Navbar

## Problema Atual
- Funcional mas sem personalidade marcante
- Fundo branco comum
- Dropdowns simples

## Design Novo

### Layout
- **Fundo:** transparente sobre hero, muda para `#111` com blur ao scrollar (backdrop-blur-xl)
- Position fixed, z-50
- Height: 64px
- Transição suave entre transparente → escuro (300ms)

### Estrutura

#### Esquerda
- Logo SW (ícone vermelho + "SWMG" em bold branco)
- Hover: logo pulsa sutilmente

#### Centro - Links
- **Sobre** — scroll para seção
- **Eventos** — dropdown:
  - Próximos Eventos (→ seção)
  - Todos os Eventos (→ `/eventos`)
  - Calendário 2026
- **Recursos** — dropdown:
  - Mentoria
  - Ecossistema
  - Blog & Notícias
  - FAQ
- **Blog** — scroll para seção
- Links: text-sm font-medium text-white/80, hover text-white
- Dropdowns: fundo `#2D2D2D`, border sutil, shadow-xl, border-radius 12px

#### Direita
- Ícone de perfil (user icon) — futuro login
- **CTA "Inscreva-se"** — botão vermelho, hover glow, border-radius full

### Mobile
- Hamburger menu (3 linhas → X animado)
- Menu fullscreen: fundo `#111` com opacity 98%
- Links grandes empilhados com animação stagger
- CTA no bottom

### Animações
- Scroll transition: `useScroll` + `useTransform` do Framer Motion
- Dropdown open: `AnimatePresence` fade + slideDown
- Mobile menu: slide from right com backdrop blur
- Hamburger → X: morphing animation
- Links hover: underline que cresce do centro
