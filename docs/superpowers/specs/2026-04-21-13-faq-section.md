# Spec 13 - FAQ Section

## Problema Atual
- Funcional mas visualmente sem personalidade
- Fundo branco genérico
- Accordion simples demais

## Design Novo

### Layout
- **Fundo escuro:** `#1A1A1A` (carvão)
- Padding: `py-20`

### Estrutura

#### Header
1. **Eyebrow:** "Perguntas Frequentes" em vermelho
2. **Título:** "Tire suas dúvidas" — text-4xl md:text-5xl, font-black, text-white
3. **Descrição:** texto atual preservado — text-gray-400

#### Search
- Input grande centralizado: fundo `#2D2D2D`, border sutil, ícone search
- Placeholder: "Buscar pergunta ou palavra-chave..."

#### Filtros de Categoria
- Pills horizontais: Todas | Geral | Inscrição | Evento | Mentoria | Pós-evento
- Ativa = vermelho, demais = `#2D2D2D` com text-gray-400

#### Accordion
- Layout: max-w-3xl centralizado
- Cada item:
  - **Fechado:** fundo `#2D2D2D`, border-radius 12px, padding 20px
  - Ícone de categoria à esquerda (vermelho)
  - Pergunta em font-semibold text-white
  - Chevron à direita que rotaciona
  - **Aberto:** expande com animação suave
  - Resposta em text-gray-400, padding top
  - Separador sutil entre pergunta e resposta
  - Border left vermelho 3px quando aberto
- Gap de 8px entre items

#### CTA bottom
- "Não encontrou sua resposta?"
- Botão "Fale conosco" → email contato@startupweekendmg.com

### Conteúdo Preservado (todas as 10 perguntas)
1. "O que é o Startup Weekend?" — Geral
2. "Preciso ter uma ideia para participar?" — Geral
3. "Preciso ter experiência em programação ou negócios?" — Geral
4. "Como funciona o processo de inscrição?" — Inscrição
5. "Qual é o valor da inscrição?" — Inscrição
6. "Os participantes são divididos em equipes?" — Evento
7. "O que acontece durante os três dias do evento?" — Evento
8. "Como funciona a mentoria durante o evento?" — Mentoria
9. "O que acontece com os projetos após o SW?" — Pós-evento
10. "Existe algum tipo de acompanhamento pós-evento?" — Pós-evento
- Todas as respostas completas preservadas

### Animações
- Items: `stagger fadeInUp` 0.05s
- Accordion open: `AnimatePresence` com height + opacity
- Chevron: `rotate(0) → rotate(180)` com transition
- Border left: `scaleY(0) → scaleY(1)` ao abrir
- Search: `fadeIn` no load
