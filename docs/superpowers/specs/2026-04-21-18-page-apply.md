# Spec 18 - Página /inscricao (Volunteer Registration)

## Problema Atual
- Form funcional mas visual genérico
- Campos em fundo escuro com pouco contraste
- Sem contexto visual do que é ser voluntário

## Design Novo

### Layout
- **Fundo:** `#FAFAF8` (claro)

### Estrutura

#### Hero da Página
- Altura reduzida (~30vh)
- Fundo: gradiente carvão → vermelho sutil
- Badge: "Voluntariado"
- **Título:** "Inscrição de Voluntários" — text-4xl font-black text-white
- **Subtítulo:** texto atual preservado

#### Split Layout
- **Esquerda (50%):** informações sobre voluntariado
  - "Por que ser voluntário?"
  - 3-4 benefícios com ícones:
    - Networking com ecossistema
    - Experiência em eventos
    - Certificado de participação
    - Conexão com mentores e investidores
  - Imagem stock de voluntários em evento
  - Depoimento de voluntário

- **Direita (50%):** formulário
  - Card branco com shadow-lg, border-radius 16px, padding 32px
  - Campos:
    1. Nome Completo — input text, required
    2. Email — input email, required
    3. LinkedIn — input url, optional
    4. Papel — select (Facilitador, Mentor, Jurado), required
    5. Evento — select (SW BH 2026, SW Uberlândia 2026), required
    6. Motivação — textarea, optional (campo novo para dar mais contexto)
  - Botão "Enviar Inscrição" — vermelho, full width
  - Nota: "Entraremos em contato em até 48h"

### Conteúdo Preservado
- Todos os campos do formulário existente
- Opções de Role: Facilitador, Mentor, Jurado
- Opções de Evento: atualizadas para 2026
- Validações (min 2 chars nome, email válido, URL válida LinkedIn)
- Título e subtítulo

### Animações
- Hero: `fadeIn`
- Benefícios: `stagger fadeInLeft`
- Form card: `fadeInRight`
- Submit button: hover glow
- Success state: confetti ou checkmark animation
